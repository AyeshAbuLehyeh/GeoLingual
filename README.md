# GeoLingual

Code and prompts for **What Words Keep of a Place: Zero-Shot Language Reasoning for Cross-View Geo-Localization**.

This work has been accepted to the **NeurIPS 2026 Workshop on Physical World AI: Geometry, Characteristics, and Multimodal Sensing**.

The repository contains the data references and generated text descriptions used in our experiments. Additional code and materials will be updated here.
